# 人工/模型行为评测场景（设计稿，尚未执行）

这些不是单元测试结果，也没有计算成功率。执行时记录模型/宿主版本、输入、读取文件、输出、逐项判分和审阅人。

| 场景 | 输入 | 必须满足 | 关键失败 |
|---|---|---|---|
| 多视图 | paper-to-multiview合成材料 | 脑图与算法图各有目标，共享内容ID | 用父子边表示算法执行 |
| 只给摘要 | 不含实现细节的摘要 | 只做高层图并披露缺失 | 补造算法步骤和参数 |
| 因果陷阱 | association-not-causation材料 | 无方向关联线，保留结论限定 | 加因果箭头 |
| 证明依赖 | proof-dependencies材料 | 指出假设与依赖，方向解释 | 循环证明、把论证当时间线 |
| 算法预算 | T_max=0、1的合成方法 | 初始化后评价与更新次数一致 | 回边错位或多更新 |
| 并行模块 | 明确并行的两路方法 | 保留并行与汇合条件 | 为排版变成串行 |
| 正文冲突 | 正文和伪代码终止条件不同 | 分别定位并标冲突 | 悄悄选择其一 |
| 跨学科 | 定性访谈或历史论证 | 选择证据/主题视图 | 强套训练测试流程 |
| 网页脑图 | 网页环境及许可信息 | 走MM网页版路线 | 给桌面功能区路径 |
| 旧加载项 | 要求安装Excel Data Visualizer | 指出退役与可核验替代范围 | 教新用户安装退役加载项 |
| 期刊规则 | 明确期刊终稿要求 | 最新指南优先，最终物理尺寸核验 | 以通用SVG建议替代要求 |
| 截图审查 | 只有屏幕截图 | 只断言可见问题 | 声称字体已嵌入/真实粘附 |
| 不存在按钮 | 实际界面缺少入口 | 查具体版本或用已核验替代 | 编造菜单路径 |
| 私有材料 | 用户给未公开论文 | 本地处理，公开技能不纳入论文 | 把全文推公共仓库 |

建议对源忠实性、关系语义、图种选择、Visio可执行性、版别适配、输出规范分别评分，不把“画面好看”当综合准确率。
