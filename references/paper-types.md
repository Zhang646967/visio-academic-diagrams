# 按研究类型理解，而非按学科名套模板

以下是本项目的提取/选图策略，不是学科通用质量认证。混合研究分别建立子模型并核对共同术语。

| 研究类型 | 必须提取 | 候选主图 | 特别防止 |
|---|---|---|---|
| 算法/优化 | 状态、变量、目标、约束、初始化、更新、终止、输入输出 | 算法流程 + 模型组成图 | 把最优性宣称替代证明；漏掉不可行分支 |
| 机器学习 | 数据划分、训练/验证/测试、可学习组件、推理阶段、损失和评估 | 训练/推理双视图 + 数据管线 | 测试集参与拟合；把损失连线当控制箭头[R02] |
| 实证/计量/管理 | 研究对象、变量角色、设计、识别条件、分析过程、局限 | 设计流程 + 概念/证据图 | 相关变量画成因果边；省略对照和样本筛选 |
| 数学/理论 | 定义、假设、引理、定理、推论、依赖方向 | 证明依赖图 + 概念图 | 把逻辑证明画成实验流程；循环依赖 |
| 系统/工程 | 模块边界、接口、消息、数据、部署、环境和评测 | 组件图 + 数据/消息流 | 实际部署与逻辑架构混在一层 |
| 定性/案例 | 案例边界、材料来源、取样、编码、主题、解释、反例 | 研究流程 + 主题关系图 | 主题包含误写为因果；把例句当总体统计结论 |
| 系统综述 | 检索来源、筛选阶段、记录/报告/研究单位、排除原因 | 筛选流程 + 证据分类图 | 缺失数量填0；不同计数单位直接相加[R01] |
| 叙述性综述 | 论题、理论谱系、比较维度、争论和开放问题 | 主题脑图 + 比较/概念关系图 | 没有系统检索却宣称PRISMA流程 |
| 实验科学 | 样品/参与者、处理条件、实验装置、采集、分析和对照 | 实验设计/样品流转图 | “样本”和“重复”混为一谈；重绘图改变数据 |
| 历史/人文论证 | 论题、材料、时期、解释框架、论证和反证 | 时间线或论证/证据图 | 自动把叙述年表转换为因果 |

不是看到某个词就选择某图。比如“框架”可能指概念理论，也可能是软件系统；应根据关系类型和图的目的判定。
对于医学、法学等高风险内容，图示不能替代专业判断；只忠实表达材料中的研究设计和证据，不自行补临床或法律结论。
