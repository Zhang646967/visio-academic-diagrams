# 文字与标签

字体是否可用及是否可嵌入需实际检查；本包不附带字体文件。

每行均须在输出给用户时展开为“选择对象→菜单→参数→预期结果→检查”。中文为辅助翻译，英文为核验锚点。

| ID / 能力 | 平台及入口 | 参数 / 动作 | 检查与回退 | 依据 |
|---|---|---|---|---|
| TX01 · 节点文字 | 桌面：选形状后直接输入 | 按节点表输入原文；编辑结束按Esc。 | 不要把编辑框位置误认为图形位置；核对自动换行。 | [M11] |
| TX02 · 字体与对齐 | 桌面：Home > Font / Paragraph | 选择节点或文字后设置字体、pt字号、段落对齐。 | 图中文字最终物理字号需另算；看起来大可能只是画布放大。 | [M11] |
| TX03 · 独立注释 | 桌面：Home > Tools > Text | 仅为面板字母或必要注释创建文本框。 | 分支标签优先附在线上，避免漂浮文字错配到别的边。 | [M11] |
| TX04 · 调整文本块位置 | 桌面：Home > Tools > Text Block | 移动或调整形状内部文字块，不移动形状本身；完成后回Pointer。 | 检查没有意外旋转文字或拖坏节点布局。 | [M11] |
| TX05 · 连接线标签 | 桌面：选中连接线后输入；必要时Text Block | 输入Yes/No或实际条件，移动标签离开箭头、节点边框和交叉处。 | 每个标签归属的边必须一眼明确。 | [M11] |

## 排版决策
最终图宽与导出宽一致时，源字号=最终字号。缩放时按设计规则重新计算。中文图选目标环境可用且允许嵌入的中文字体；不能把Arial当作所有中文字形均存在的保证。
数学表达先确保语义准确，再考虑上下标与希腊字母。复杂公式不要用多个浮动小文本框拼成不易维护的字符阵列；可简化为符号并在正文定义。
本包没有核验特定版本的公式编辑器或LaTeX原生支持，因此不得保证存在这两个入口。
