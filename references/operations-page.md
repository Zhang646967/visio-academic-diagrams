# 页面与保存

先区分绘图页、打印纸和论文中的实际图宽；本包坐标用于绘图页。

每行均须在输出给用户时展开为“选择对象→菜单→参数→预期结果→检查”。中文为辅助翻译，英文为核验锚点。

| ID / 能力 | 平台及入口 | 参数 / 动作 | 检查与回退 | 依据 |
|---|---|---|---|---|
| PG01 · 新建基础流程图 | 桌面：File > New | 搜索 Basic Flowchart（基本流程图），选择可用模板并创建。 | 若模板不存在，先核对平台；普通矩形只是非标准示意替代，不冒充专用模板。 | [M02], [M03] |
| PG02 · 自定义绘图页 | 桌面：页面标签右键 > Page Setup > Page Size | 设置设计宽高，如180 mm ×130 mm；仅当前页。 | 核对绘图页宽高而非Print Setup纸型；已有背景页另核对。 | [M12] |
| PG03 · 拟合绘图边界 | 桌面：Design > Size > Fit to drawing | 只在允许改变页面边界时使用。 | 会影响导出尺寸与坐标基准；使用后重测实际宽度并重算缩放。网页见WB01。 | [M12] |
| PG04 · 打印纸设置 | 桌面：Page Setup > Print Setup | 只在打印任务中设置纸张或Fit to页数。 | 1×1适合打印不代表物理尺寸不变；不能据此宣称投稿字号合格。 | [M12] |
| PG05 · 保存可编辑源文件 | 桌面：File > Save As | 另存有意义名称，例如fig01_method_v01.vsdx；保留未裁切工作版。 | 检查类型、路径、页数；首次改动另存副本，不覆盖唯一版本。 | [M02] |

## 精确坐标前提
基础流程图不需要工程比例。核对Page Setup中的绘图比例为无缩放/1:1；若该选项与界面不同，先检索[M05]页面设置相关条目，不猜工程换算参数。
不要在输入固定坐标后再改变绘图比例。自动扩页使尺寸变化时，先移回越界对象，再按PG02重设页面并检查预览。
