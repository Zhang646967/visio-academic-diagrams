# Visio网页版单独路线

适用性依据官方网页选项卡；仍需核验实际账户与更新。

每行均须在输出给用户时展开为“选择对象→菜单→参数→预期结果→检查”。中文为辅助翻译，英文为核验锚点。

| ID / 能力 | 平台及入口 | 参数 / 动作 | 检查与回退 | 依据 |
|---|---|---|---|---|
| WB01 · 网页画布 | 网页：Design > Size / Orientation | 选择提供的预设纸型和方向；无限画布与页面边界另行检查。 | 旧Auto Size/Fit to Drawing多数已不提供；不沿用桌面PG03。 | [M12] |
| WB02 · 网页形状格式 | 网页：Shape > Shape Fill / Shape Outline > Weight | 设置填充与轮廓；另有右键Format Options。 | 不保证桌面数值框、效果选项完全一致。 | [M18] |
| WB03 · 网页容器 | 网页：Insert > Container | 先核验Plan 1/Plan 2；不是所有Visio in Microsoft 365环境都有。 | 检查成员；删除前保护内容。 | [M17] |
| WB04 · 网页BPMN门槛 | 网页：Shapes搜索BPMN | 官方页面说明Plan 2且English-US区域；按该页重核验当前情况。 | 网页不能执行桌面BPMN规则校验；不是把中文菜单翻译一下即可解决。 | [M29] |

## 网页任务的降级策略
对齐参见LY04；输出参见EX03。若任务必须毫米级绝对坐标，但实际网页版缺少可核验的输入面板，应交付相对布局步骤，并标注尚未达到桌面数值复现精度。
此时不要假称“完全按照桌面做就行”，也不要静默改成另一种软件。可以保留原设计，说明转到具备相应面板的桌面版才能采用本包精确坐标路线。
