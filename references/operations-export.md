# 保存、导出与最终尺寸

先读publication-profiles.md。`.vsdx`用于继续编辑；审阅文件与投稿文件不是同一个概念。

每行均须在输出给用户时展开为“选择对象→菜单→参数→预期结果→检查”。中文为辅助翻译，英文为核验锚点。

| ID / 能力 | 平台及入口 | 参数 / 动作 | 检查与回退 | 依据 |
|---|---|---|---|---|
| EX01 · 导出PDF | 桌面：File > Export > Create PDF/XPS Document > Create PDF/XPS | 核对Options页码与输出文件名后Publish。 | 检查真实页面尺寸、页数、裁切、字体、细线；PDF中仍可能含栅格元素。 | [M13] |
| EX02 · 导出图形格式 | 桌面：File > Export > Change File Type | 按可用类型选择SVG、PNG、EMF等，再Save As；TIFF可能在其他类型中。 | 格式由期刊决定；不声称SVG必被投稿系统接受。 | [M13] |
| EX03 · 网页导出 | 网页：File > Save As > Download as PDF / 图像下载选项 | 网页PDF导出全部页面；PNG/JPEG选项中核对分辨率及页面。 | 不套用桌面SVG菜单；单页交付先避免多余页，导出后复核。 | [M13] |

## 本包的输出质量流程
**工作版**：保留.vsdx与设计规格，不覆盖唯一原稿。
**审阅版**：优先可放大的PDF；需要网页预览时可选SVG或PNG，但不称为“投稿已合规”。
**投稿版**：仅输出目标期刊当前接受的类型。没有格式要求时暂称“候选交付”，不可代替编辑部规则。

令导出实际宽度为W_e毫米、最终插入宽度为W_f毫米，则缩放s=W_f/W_e。最终字号=源字号×s；最终线宽=源线宽×s。若裁切、Fit to drawing或排版软件改变了边界，必须用新的W_e。
栅格最低像素宽度=ceil(W_f/25.4×目标dpi)。增加元数据dpi而不增加真实像素不提高细节。

以PDF查看器的字体属性或实际文件检查字体嵌入；如果工具不支持这项检查，明确写“未验证”。不能凭文件扩展名或一张截图判断。不得承诺Visio必定将所有字体转为轮廓。
出版系统只收EPS时，不编造Visio的“导出EPS”菜单。可按允许格式选择TIFF，或明确提出另行使用已核验的转换工具并重新检查字体/矢量属性。
不要为了提交而把原图压成JPEG、截图再贴回PDF，或将低分辨率截图放大伪装为线稿。
