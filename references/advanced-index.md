# 高级与长尾功能索引

本表表示“知道应去哪里查”，不是“已经学完每个功能”。使用任一条目时先打开官方来源的精确相关章节，确认平台、版别与适用范围后再给操作。

| ID | 功能族 | 下一步 | 来源 |
|---|---|---|---|
| AD01 | 组合、取消组合、选择层级与主控形状 | 进入Shapes目录查Select/move/group、master与stencil；先核对实际子页再给菜单。 | [M04] |
| AD02 | 自定义形状与复杂几何 | 先查原生几何/自定义形状章节；不要把位图包装称为原生可编辑几何。 | [M26] |
| AD03 | ShapeSheet单元格和公式 | 按所需单元格检索；注意旧版文档背景与形状保护。 | [M20] |
| AD04 | VBA与桌面对象模型 | 核验Windows桌面、对象方法及授权；用户明确请求自动化后再设计最小测试。 | [M21] |
| AD05 | 嵌入图表JavaScript API | 先确认嵌入宿主能力；不是通用桌面VSDX写入接口。 | [M22] |
| AD06 | 数据图形和数据驱动展示 | 从Diagrams查Data Graphics；图标规则不能替代定量统计图。 | [M06] |
| AD07 | 透视关系图及商业图 | 查PivotDiagram与marketing diagrams，先核验版别和数据来源。 | [M06] |
| AD08 | 组织结构与泳道流程 | 查organization chart或cross-functional flowchart，区分职责与数据流。 | [M06] |
| AD09 | 网络拓扑、机架和网络资源 | 查network/rack diagrams；图标库可用性按版本确认。 | [M06] |
| AD10 | 平面图、建筑及工程专业图 | 查floor/HVAC/electrical/site等；工程比例需单独设置，不套科研1:1布局。 | [M06] |
| AD11 | AutoCAD导入、裁切、转换与图层 | 查AutoCAD drawing章节；文件版本和对象可编辑性另外验证。 | [M06] |
| AD12 | 价值流、IDEF0、SDL、EPC与故障树 | 按图种进入专题；不得把普通形状配方当成全部专用规则。 | [M06] |
| AD13 | 共享、协作与评论 | 从帮助与协作入口查当前存储和账户要求；本包不自动上传用户研究资料。 | [M01] |
| AD14 | 主题、背景、边框及多页面 | 从Format pages目录定位；科研终稿使用前检查是否改变既有格式。 | [M05] |
| AD15 | 跨页引用与超链接 | 先查跨页说明，避免把同页连接器错误跨页延伸。 | [M09] |
| AD16 | 捕捉、网格、标尺、参考线 | 从页面格式/对齐辅助专题定位；本包没有承诺所有宿主的数值面板一致。 | [M05] |
| AD17 | 结构化图规则校验 | 读适用模板、规则与问题窗格，区分形式规则和科学正确性。 | [M25] |
| AD18 | UML专用图种 | 先确认UML图种与符号，再读对应子文章。 | [M28] |
| AD19 | ER建模与数据库反向工程 | 版别/驱动/连接能力分别核验，默认不执行数据库连接。 | [M24] |
| AD20 | DFD与数据流程 | 读取具体模板与约定；不要用控制流程图替代数据语义。 | [M27] |
| AD21 | BPMN专用记法及验证 | 读桌面/网页及地区限制；无标准验证时不宣称完全合规。 | [M29] |

## 不属于首版承诺
不提供所有菜单的逐项全量清单，不包含任何微软教程全文镜像；没有测试每种CAD文件、数据库驱动、主控形状或API。平台功能变化后，先更新来源与兼容性，再升级条目状态。

## 未命中功能时的检索协议
保留用户原词；先在M01/M04/M05/M06合适入口定位。找不到时明说未建立索引，继续检索官方帮助或开发文档；不要把未知功能默认为不存在，也不要拼接未经打开的URL充当证据。
