# 环境、版本与可信度

## 执行前记录
记录 desktop/web、版本或订阅、界面语言、文件是否可编辑、页面单位、绘图比例及目标投稿渠道。未知项不补成事实。
只需先声明默认假设即可继续设计。用户遇到具体按钮不一致时，再让其发相关局部截图；不要求一开始填写冗长问卷。

## 采用的默认草案环境
Windows 桌面版；以官方英文功能名为准并提供中文辅助名称；毫米、绘图比例1:1、中心针脚、左下角原点。精确的版本兼容性需用户实机确认。
桌面版和网页版有不同教程选项卡；阅读时必须选对。[M02]

| 功能族 | 默认策略 |
|---|---|
| 基本框线和文字 | 采用核心模块，先确认工具区实际可见 |
| 自定义页面和精确坐标 | 以桌面模块指导；网页不假定存在同样面板 |
| 数据连接、模板、BPMN、容器 | 先看每篇正文的授权、平台与地区限制 |
| ShapeSheet / VBA | 高级路由，不能把普通网页账户视为拥有桌面自动化环境 |
| 投稿规则 | 目标期刊官方说明优先，其次出版社总则，最后本包通用建议 |

## 操作证据标记
`document-backed`：官方文档明确支持动作；`design-choice`：本包设计值；`verify-in-ui`：用户版本待核验；`index-only`：仅提供入口，不能输出保证可执行的长教程。
中文标签因版本可能略有区别；若中英文都找不到，不能连续猜三个路径当成官方步骤。

## 原点/针脚
Visio的X/Y是形状针脚相对原点的位置，不一定是左上角。[M07]
本包先要求中心针脚；可用临时矩形设X=0、Y=0观察中心是否落在绘图页左下角，再撤销。若模板改变了原点/比例，先调整或转换整张坐标表。
有些专用主控形状会受保护、自动增高或有内部坐标；尺寸被改回时先查该形状，不强行堆叠操作。

## 网页状态快照
当前官方说明网页采用无限画布，旧Auto Size/Fit to Drawing多数不再提供；不能让网页用户照桌面旧教程找此按钮。[M12]
所有版本/订阅/在线界面结论均为2026-09-12文档快照；遇到差异需重新核验。
