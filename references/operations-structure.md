# 容器、图层与数据

科研静态流程图通常不需要外部数据连接；按任务选择。

每行均须在输出给用户时展开为“选择对象→菜单→参数→预期结果→检查”。中文为辅助翻译，英文为核验锚点。

| ID / 能力 | 平台及入口 | 参数 / 动作 | 检查与回退 | 依据 |
|---|---|---|---|---|
| ST01 · 建立容器 | 桌面：选成员 > Insert > Diagram Parts > Container | 选同一语义模块中的对象再插入容器。 | 拖动容器并撤销来检查成员；几何上围住不等于成为成员。 | [M17] |
| ST02 · 解散容器 | 桌面：容器相关菜单 > Disband Container | 需要保留内容时用解散，具体上下文入口核对当前界面。 | 直接删除容器可能连成员一起删除；先保存副本。 | [M17] |
| ST03 · 分配图层 | 桌面：Home > Editing > Layers > Assign to Layer | 建立语义或审阅图层并分配对象。 | 对象可属于多个层，需检查实际归属。 | [M14] |
| ST04 · 图层属性 | 桌面：Home > Layers > Layer Properties | 按任务设置可见、打印、锁定；明确审阅辅助层是否打印。 | 图层颜色可覆盖对象且影响打印；删层前检查是否会删对象。 | [M14] |
| ST05 · 查看形状数据 | 桌面：View > Task Panes > Shape Data | 查看或填写需要的元数据。 | 元数据不一定自动显示为可见标签。 | [M02] |
| ST06 · 导入并刷新外部数据 | 支持的数据功能版别：Data > Quick Import / Custom Import | 核对唯一键和源文件；导入后将External Data记录关联到形状，Refresh All更新。 | 此导入路径的形状数据修改不反写源数据；与ST07不同。 | [M16] |

## ST07 · Data Visualizer（索引级，不是通用自动制图承诺）
官方文档描述Plan 2中的Excel过程数据转图，以及该工作流的双向同步。[M23]
先核验用户订阅和模板，再读取源/目标ID、分支列的正式映射要求。普通数据链接不是同一个功能，不能混写同步方向。不同Excel加载项和桌面模板也不能仅凭名字相近就断言生命周期相同。

## 结构选择建议
容器表达模块成员，泳道表达责任主体；一个普通背景矩形只能表达视觉分区。需要移动整个模块时先检验成员关系，避免只移动背景。
公开投稿版剥离不需要的外部链接与敏感元数据，保存工作原版以便修改；不在未授权时上传任何数据。
