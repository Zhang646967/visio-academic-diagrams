# 常见问题：先定位原因，再给动作

| 现象 | 优先检查 | 处理与验证 |
|---|---|---|
| 找不到指定菜单 | 桌面/网页、语言、版本、上下文选中对象 | 对照environment；只有已核验的替代入口才能给出；仍缺失就获取该局部截图 |
| X/Y正确但位置错 | 针脚、原点、绘图比例、是否进入组合内部 | 按SH03校准；不要翻转Y值“试试看”后继续 |
| 大小录入后变了 | 文本自动换行、主控形状保护/行为 | 复查Width/Height；先换行或调整设计，特殊形状走高级索引 |
| 框移动线断开 | 端点未粘附、Glue只影响新连接 | 按CN05启用后把既有端点重新接上，移动并撤销复查 |
| 反馈回边乱跳 | 动态换边、自动路由、错误全图重排 | 用CN02指定连接点，再CN04调中段；固定后不自动重排 |
| 标签压住线或边框 | 文字块位置或边距 | TX04/TX05移动文本块；不要移动节点冒充移标签 |
| 删除外框把内容删了 | 把容器当普通矩形 | 先撤销；核验成员，必要时使用解散容器ST02 |
| 屏幕可见但打印消失 | 图层打印/可见属性 | ST04复核，而不是简单把对象再画一次 |
| PDF页数或空白异常 | 多余页、打印分页、背景页、对象越界 | 核对PG02/EX01，网页注意EX03全部页行为 |
| 插进论文后字太小 | 最终宽度比原导出窄 | 按缩放公式重算，改为单栏布局或增大源字号后重查文本容纳 |
| 格式正确但仍模糊 | 内嵌低分辨率图、截图、真实像素不足 | 检查元素与像素；改扩展名/标称dpi不能补细节 |
| PDF中的数学符号缺失 | 字体替换或没有嵌入 | 核验实际文件字体；替换为允许且支持字形的字体后重导出 |
| “标准校验通过”却逻辑错 | 形式规则不验证科研含义 | 回到原文逐边检查；BPMN校验边界见[M29] |

操作细节与证据对应：坐标[M07]、文本[M11]、连接[M09][M10][M19]、容器[M17]、图层[M14]、导出[M13]。其余因果诊断是待验证假设，不应凭现象自动认定。
