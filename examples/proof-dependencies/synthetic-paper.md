# Sum of squares — synthetic teaching note

## P1
Let x_1,...,x_n be a finite sequence of real numbers, where n is a positive integer.

## P2
For each i, x_i squared is nonnegative. This uses the real-number assumption.

## P3
The finite sum of these squares is nonnegative because each summand is nonnegative.

## P4
This statement does not require the original x_i values to be nonnegative. This note is a teaching example, not a claim of novel research.
