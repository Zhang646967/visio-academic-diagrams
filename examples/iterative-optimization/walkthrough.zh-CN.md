# 完整实例：带终止判断与反馈回路的优化流程

这是一套可以照表手工实现的设计，不是已经在Visio打开检查过的源文件。示例原文见[request.md](request.md)，机器可读规格见[diagram-spec.json](diagram-spec.json)。

## 1. 条件与设计结论

采用Windows桌面版操作路线；具体版本未确认。绘图比例1:1，中心针脚、左下角原点、毫米；绘图页和最终图均180×130 mm，因此不缩放。期刊未知，样式只是通用草案。
主链在x=62 mm竖排。判断的Yes向右到输出，No向下到下一候选；反馈绕到左侧x=14 mm，从N5回到N3，不返回初始化。
全部文字Arial 8.5 pt、黑色；节点白色，边框及连接线0.75 pt，无阴影。开始/结束用模板端点，处理用矩形，判断用菱形，输入/输出用对应形状。
若目标期刊采用IEEE通用字号建议，应重新改为约9–10 pt并检查文本；本例并不声称IEEE合规。规则见[期刊配置](../../references/publication-profiles.md)。

## 4. 逐步操作

### 步骤1：创建并保护工作文件
在File（文件）> New（新建）中选择Basic Flowchart（基本流程图）。用File > Save As另存为`fig01_iteration_v01.vsdx`，保存到你选定的本地位置。不要覆盖已有唯一原稿。检查当前只有需要的绘图页。[M02][M03]

### 步骤2：设置绘图页，而不是打印纸
右键底部当前页面标签 > Page Setup（页面设置）> Page Size（绘图页大小），设置180 mm宽、130 mm高。也可从Design中的Page Setup对话框启动器进入。检查当前页边界；Print Setup纸型不用于替代这两个数值。[M12]
核对绘图比例为无缩放/1:1。若界面名称不同，先按[环境规则](../../references/environment.md)查证，不进入工程比例换算。

### 步骤3：打开精确尺寸面板并校准
View（视图）> Task Panes（任务窗格）> Size & Position（大小和位置）；部分界面Task Panes在Show组下。先拖入一个临时Process框，把Pin Pos选中心，设X=0 mm、Y=0 mm；确认中心在页面左下角后撤销并删除临时框。坐标与预期不符就先处理原点/比例，再继续。[M07]

### 步骤4：创建N0开始节点
从形状窗格拖入Start/End（开始/结束）形状，输入`Start`。选此节点，在Size & Position依次填Width=28 mm、Height=8 mm、中心针脚、X=62 mm、Y=118 mm、Angle=0°。检查节点在页面上方但未越界。[M03][M07]

### 步骤5：创建输入和处理节点N1、N2、N3
按节点表逐个拖入相应形状、输入两行标签，并用同一面板设置宽、高、X、Y。不要用目测替代数值，也不要把N1的输入/输出形状当成决定分支的菱形。每完成一个就核对文字和大小。[M03][M07][M11]

### 步骤6：创建判断N4和下一候选N5
拖入Decision，输入`t ≥ T_max?`，设40×18 mm、中心(62,38)。拖入Process，输入N5两行标签，设70×14 mm、中心(62,14)。确保N4与N5间有8 mm边界净距；这里不是中心距离。[M03][M07]

### 步骤7：创建输出N6和结束N7
按表在右侧创建N6与N7。N6中心(137,38)，N7中心(137,17)。这些节点表示终止后的结果，不是在每次迭代后都输出。[M03][M07]

### 步骤8：统一字体与节点外观
逐个或明确多选这8个节点，在Home > Font / Paragraph设Arial、8.5 pt及居中；右键Format Shape > Fill & Line设白色填充、黑色实线、0.75 pt。检查Effects无多余阴影。逐一复核两行文字没有溢出；输入文字后再次检查Size & Position。[M11][M18]
8.5 pt和0.75 pt是本例设计值，不是微软或全部期刊要求。若本机字体缺少≥/←字符，先换为支持且允许使用的字体，再复查标签。

### 步骤9：连接主链E1–E4
Home > Tools > Connector，或Ctrl+3。逐条从N0下侧到N1上侧、N1下侧到N2上侧、N2下侧到N3上侧、N3下侧到N4上侧的连接点拖动。按Ctrl+1回指针。移动N2一小段，看相邻连接端是否跟随，然后撤销。[M09][M10]

### 步骤10：连接Yes出口E5
用同一工具从N4右侧接N6左侧。选这条连接线直接输入`Yes`，用Home > Tools > Text Block将文字移到连接线附近、不压框的位置；建议中心约(98,42) mm，属于目视放置目标。完成后回Pointer。确保标签只可能被读成E5的条件。[M10][M11]

### 步骤11：连接No出口E6及结束边E7
从N4下侧连N5上侧，输入`No`，将标签放在短竖线右侧，目视中心约(66,25) mm。再从N6下侧连N7上侧，无标签。核对Yes并没有误连到N5。[M09][M11]

### 步骤12：制作左侧反馈E8
用Connector从N5左侧连接点连到N3左侧连接点。选择该线，在Design > Layout > Connectors选Right-Angle，或用已提供该选项的右键菜单。拖动线段中点，使路线先向左到x≈14 mm，再向上至y≈63 mm，最后向右进入N3。[M10]
这不是要求在不存在的“折点坐标表”中输入数值。走廊以页面标尺/网格和节点位置为参照；控制目标是不穿任何框，并保留真实粘附。若连接点位置不可用，先依CN06添加连接点，再连接。

### 步骤13：统一箭头和线宽
逐条核对8条边，右键连接线 > Format Shape > Line，选择0.75 pt实线，Begin Arrow设无，End Arrow设一致的实心箭头。检查箭头都在目标节点端，尤其E8应指向N3。专用记法图不能照此任意重设其连接语义。[M10]

### 步骤14：做逻辑和粘附检查
N3首次评价时，将当前候选设为最好解；后续按输入问题规定的优化方向比较并更新。

手工走t=0、T_max=0的路径：初始候选被评价一次，然后Yes→输出→结束。再走T_max=1：评价初始候选，No→更新且t=1，再评价一次，然后Yes结束。该示例是T_max次更新、T_max+1次评价；它不是另一种“先检查后评价”的算法。
每个节点轻微移动并撤销，检查所有相接端点跟随；这一步不能由JSON代替。不要在此后对全图自动重排。

### 步骤15：保存源文件并导出审阅PDF
保存.vsdx。File > Export > Create PDF/XPS Document > Create PDF/XPS，检查Options页码并Publish为`fig01_iteration_review.pdf`。打开后核对1页、180×130 mm、文字完整、无裁切。不要用打印到A4后自动缩放的结果代替此检查。[M13]

### 步骤16：放入论文并复检
以180 mm实际宽度放入稿件，按最终物理尺寸阅读。若模板只允许90 mm，不直接缩半：那会把8.5 pt缩成4.25 pt；应重新设计单栏布局。放大检查线与字体符号；检查嵌入情况时使用文件级证据，而不是凭截图判断。
目标期刊尚未知，因此这里只得到工作源文件与候选审阅PDF。投稿格式须按[出版配置](../../references/publication-profiles.md)重新选择。
