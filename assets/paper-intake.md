# 论文/思路输入模板

材料：标题、版本、全文/片段/摘要/口述思路；真实文件或链接。
目标：阅读理解 / 论文插图 / 方法复现 / 组会交流。
研究类型：算法、实证、理论、系统、综述、定性、混合或其他。
已读范围：具体章节和页码；图表、公式、附录的可访问状态。
核心问题、对象、假设、贡献、方法、证据、结果、局限。
术语/变量：原文、中文释义、定义定位、同名冲突。
事实状态：原文明确 / 有依据推断 / 提议 / 未知。
图需求：读者要理解什么、哪些关系必须保留、是否需多个视图。
Visio：平台、版别、版本、语言；未知时标假设，不重复问已给信息。
出版：期刊/会议、指南日期、宽度、允许格式；未提供时只做通用草案。
隐私：不将论文、数据、截图或来源摘录自动写入公开仓库。
